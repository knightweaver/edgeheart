# Edgeheart Legacy Runtime Notes

The final pre-migration Edgeheart line is **v0.1.1**.

Declared package support:

- Foundry VTT **13.x**
- Daggerheart **1.2.x**

Original full runtime qualification:

- Foundry VTT **13.351**
- Daggerheart **1.2.7**

Installation manifest:

`https://github.com/knightweaver/edgeheart/releases/latest/download/module.json`

A prior tagged release can be installed by replacing `latest` in the release
URL with its tag.

This legacy line is intentionally frozen before migration to Foundry 14 /
Daggerheart 2.x. The migration should preserve the v0.1.1 source/content baseline
as the regression reference.
